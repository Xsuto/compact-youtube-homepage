# Compact YouTube Homepage

A small Chrome extension that displays more, smaller video cards per row on the YouTube homepage and hides the **Includes paid promotion** overlay on thumbnail previews.

## Install

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder.
5. Reload the extension and any open YouTube tabs.

## Customize

Edit `compact-youtube.css` to change the number of items shown at each screen width. After editing it, open `chrome://extensions`, find this extension, click its reload button, and reload YouTube.
